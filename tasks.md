1. clone your own repository into your `~/github` folder or what ever you chose! **NOT* into the `NSCI0032-25-26` repository!
2. create a new branch called `update_readme` and check it out 
3. update your `readme.md` file with a nice quote you like! (in the new branch!)
4. commit the changes (git status, git add, git commit) 
5. push the new branch into the origin (i,.e your github repo) 
6. create a pull request
7. merge
8. go back to main branch 
9. update !
